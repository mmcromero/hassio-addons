# Changelog

## 0.1.0 — 2026-11-28
- Primeira versão do add-on interno Media Bridge.
- Modo seguro de inicialização sem credenciais.
- Integração FileBrowser Quantum com descoberta dinâmica do prefixo Ingress.
- Listagem, metadados, previews, criação de pastas, movimentação de arquivos e quarentena.
- SHA-256 antes/depois de movimentações.
- API interna protegida por chave dedicada; sem publicação de porta no host.
