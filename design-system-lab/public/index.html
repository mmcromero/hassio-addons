Configuração única

  1. Crie um Fine-grained Personal Access Token no GitHub.
  2. Restrinja o acesso ao repositório mmcromero/design-system.
  3. Conceda somente Contents: Read-only.
  4. No Home Assistant, abra a configuração deste app e informe o token em github_read_token.
  5. Volte aqui e execute a validação.

Não cole o token no chat, no GitHub, na tela do laboratório ou em logs. Use somente a configuração protegida do app.
