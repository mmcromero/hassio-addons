Mais liberdade, menos equipamentos

A praticidade do pager. Sem o pager.

Aparelhos físicos exigem compra, manutenção, carregamento e reposição. O Avisaqui leva o acompanhamento para o celular do cliente, sem transferir a responsabilidade por um equipamento emprestado.

Para o estabelecimento, menos trabalho com hardware. Para o cliente, uma espera mais confortável — com a possibilidade de consultar o andamento do pedido.

Simples do começo ao fim

Como funciona?

Do registro do pedido até o aviso de retirada, tudo segue um fluxo fácil de entender.

①

Registre o pedido

Receba pedidos pela integração com PDV ou faça o cadastro manual no painel.

②

Compartilhe o QR Code

O cliente abre o acompanhamento pelo código impresso ou por um link enviado pelo atendente.

③

Avise quando estiver pronto

A equipe atualiza o pedido e o cliente recebe o aviso pelos recursos disponíveis em seu aparelho.

Tecnologia pensada para o mundo real

Sinal fraco? A gente pensou nisso.

Nem todo lugar tem uma conexão perfeita. Por isso, o Avisaqui foi desenvolvido com uma estrutura leve, que utiliza poucos dados e transmite apenas as informações necessárias.

Tudo para facilitar o acompanhamento dos pedidos, mesmo em locais onde o sinal de internet é limitado, como praças de alimentação e subsolos de shoppings.

*O funcionamento depende de uma conexão ativa com a internet, por Wi-Fi ou rede móvel. A entrega dos avisos não é garantida durante a ausência de conexão.

Do caixa à cozinha

Uma operação mais organizada.

No painel KDS, a equipe acompanha pedidos em preparo, sinaliza os que estão prontos e registra as entregas. Caixa, cozinha e balcão podem trabalhar no mesmo fluxo, com acessos controlados.

Cadastro rápidoUse numeração automática ou o número que o estabelecimento já utiliza.
QR Code para impressãoImprima ou reimprima o comprovante de acesso individual.
WhatsApp manualCompartilhe o link ou avise sobre a retirada, com envio feito pelo atendente.

Integração e flexibilidade

Conecte o Avisaqui ao seu PDV.

O sistema está sendo preparado para receber pedidos automaticamente do software de vendas e incluir o QR Code no comprovante, sem criar uma etapa extra na rotina do caixa.

Funcionalidade prevista para o piloto. Requer a instalação de um software auxiliar no computador do estabelecimento. A compatibilidade depende do sistema de vendas, da impressora e da configuração utilizada.

A integração ainda está em desenvolvimento e depende de testes de compatibilidade e homologação.

✎

Também funciona sem integração

Cadastre pedidos manualmente, gere o QR Code e utilize o mesmo acompanhamento. O estabelecimento pode começar com uma operação simples.

Acessibilidade desde o projeto

Um aviso que pode chegar de diferentes formas.

O Avisaqui foi pensado para diferentes necessidades. O desenvolvimento segue como referência as diretrizes WCAG 2.1 AA e prevê suporte a leitores de tela, como TalkBack e VoiceOver.

♫

Som

Alerta sonoro quando permitido pelo navegador e pelas configurações do aparelho.

✦

Visual

Mudanças de estado com texto e destaque visual de fácil identificação.

≋

Vibração

Alerta tátil em aparelhos e navegadores compatíveis.

A disponibilidade de cada alerta depende do dispositivo, das permissões e das condições de uso. A conformidade com WCAG 2.1 AA ainda requer validação.
